# Новое место

Мобильное приложение для двоих. React, TypeScript, Vite, Tailwind, Lucide, Motion, Dexie, Zod, Vitest, vite-plugin-pwa. Три вкладки: Добавить, Планы, Побывали. Без сервера и платных сервисов.

## Запуск
Установите Node.js 22 LTS или новее с https://nodejs.org, перезапустите терминал и откройте его в папке проекта:

    npm ci
    npm run dev

Проверка и сборка:

    npm run typecheck
    npm test
    npm run build
    npm run preview

Откройте адрес, напечатанный Vite. Для проверки подпапки в PowerShell:

    $env:VITE_BASE_PATH='/novoe-mesto/'
    npm run build
    npm run preview

При preview оставьте то же значение переменной. Для корня используйте /. Можно задать путь в .env.local по примеру .env.example. Путь должен начинаться и заканчиваться /. PNG-иконки уже включены; пересоздание: npm run icons.

## Бесплатная публикация GitHub Pages
1. Создайте аккаунт GitHub и новый публичный репозиторий, например novoe-mesto. Не добавляйте README на GitHub: он уже есть здесь.
2. Установите Git и выполните в папке проекта:

       git init
       git add .
       git commit -m "Create Novoe Mesto PWA"
       git branch -M main
       git remote add origin https://github.com/USERNAME/REPOSITORY.git
       git push -u origin main

Замените USERNAME и REPOSITORY реальными значениями. Авторизуйтесь стандартным способом; токены не помещайте в исходники.

3. Откройте Settings → Pages → Build and deployment → Source → GitHub Actions.
4. Actions → Publish to GitHub Pages → Run workflow. Дальнейшие push в main запускают публикацию автоматически.
5. После успешного выполнения ссылка будет в Settings → Pages и окружении github-pages:

       https://USERNAME.github.io/REPOSITORY/

Workflow получает base path из configure-pages, устанавливает зависимости через npm ci, проверяет TypeScript, запускает тесты, собирает dist и публикует через upload-pages-artifact и deploy-pages. Покупать домен не нужно; HTTPS предоставляет GitHub Pages.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## iPhone
Откройте опубликованный HTTPS-адрес в Safari, дождитесь полной загрузки, нажмите Поделиться → На экран «Домой» → Добавить. Запускайте с иконки. После успешной первой загрузки функции коллекции доступны офлайн; внешним картам нужен интернет. Локальный адрес 127.0.0.1 работает на компьютере и не является опубликованной ссылкой для iPhone.

## Обновления
Измените исходники, выполните проверки, затем commit и push в main. Actions публикует новую версию. При обнаружении нового Service Worker появляется «Доступно обновление». Сохраните открытые формы и нажмите «Обновить». IndexedDB не очищается. Проверка обновлений идёт при запуске и ежечасно при открытом приложении.

База novoe-mesto, схема Dexie версии 1. При изменении модели добавляйте новую версию и миграцию через db.version(N).stores(...).upgrade(...). Не меняйте имя базы и не переписывайте уже выпущенную версию схемы. Проверяйте миграции на копии. Формат JSON версионируется отдельно.

## Резервные копии
Настройки справа сверху → Сохранить копию. На поддерживаемых устройствах используется системное «Поделиться»: сохраните JSON в «Файлы». Иначе файл скачивается. Имя: novoe-mesto-backup-YYYY-MM-DD.json.

Восстановить из копии → выберите JSON → подтвердите замену. Все текущие записи и имена будут перезаписаны. Сначала сохраните текущую копию. Валидация происходит до изменения базы, замена — одной транзакцией. При ошибке прежние записи остаются целыми.

Записи не отправляются в GitHub. У каждого устройства и профиля собственная база. При смене адреса сначала экспортируйте коллекцию и восстановите её по новому адресу. iOS может удалить данные сайта; очистка Safari и удаление PWA могут привести к потере записей. Регулярно сохраняйте копии.

## Поведение
Для кафе персональный рейтинг появляется только после всех трёх критериев: еда, атмосфера, интерьер. Для остальных категорий — эмоции. Оценки необязательны. Общий балл учитывает только завершённые персональные оценки без промежуточного округления.

Смена схемы категории требует подтверждения очистки оценок; комментарии сохраняются. Возврат в планы очищает дату и данные посещения после подтверждения. Случайный выбор использует все планы и не повторяет предыдущий вариант при наличии нескольких мест. При сортировке по баллу записи без рейтинга в конце.
