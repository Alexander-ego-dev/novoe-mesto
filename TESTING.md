# Проверки

Автоматические команды: npm run typecheck, npm test, npm run build, npm audit.

28 тестов: ресторанные полные и частичные оценки, один и два человека, среднее архива, календарные даты, локальная дата, безопасные ссылки, структура и версия JSON, уникальные ID, диапазон оценок, совместимость категории, сортировка и случайный выбор. IndexedDB через fake-indexeddb: создание, обновление одной записи, повторное открытие, вторая оценка позже, удаление, экспорт, восстановление, отказ при неверном JSON и откат транзакции при сбое записи.

В браузере компьютера проверена production-версия в /novoe-mesto/: загрузка, добавление кафе со ссылкой Яндекс Карты и заметкой, планы, подробности, форма посещения, оценки 4/5/4 и 5/4/5, комментарий, общий балл 4,5 и переход в историю.

## Ручные проверки iPhone и публикации
Физический iPhone и опубликованный GitHub Pages здесь не проверены.

1. Safari: установка на экран Домой, отдельное окно и иконка.
2. Маленький экран: safe areas, отсутствие переполнения, работа клавиатуры, поля не вызывают zoom, прокрутка длинного диалога.
3. После онлайн-загрузки закройте приложение, включите авиарежим, откройте с иконки. Проверьте просмотр, добавление, редактирование, удаление, оценки, фильтры, сортировку, случайный выбор и экспорт.
4. Перезапустите телефон: записи и имена должны сохраниться.
5. Экспорт в «Файлы» и импорт: восстановите JSON и проверьте все данные. Повреждённый JSON не должен менять базу.
6. Имена, пустые оценки, частичные критерии, вторая оценка позже, смена схемы категории и возврат в планы.
7. Удаление с отменой и подтверждением. Случайный выбор при нуле, одном и нескольких планах.
8. Опубликуйте новую версию, сохраните формы, нажмите Обновить: данные должны сохраниться.
9. На настоящем Pages: CSS, JS, шрифты, manifest, start_url, scope, иконки и Service Worker.
10. VoiceOver и клавиатура: подписи полей, звёзд, закрытие диалога и возврат фокуса.

Service Worker кеширует статические файлы приложения и локальные шрифты. Внешние карты не кешируются. Сборка подтверждает создание кеша, но полный офлайн-сценарий iOS требует ручной проверки.
Дополнительно в браузере проверено применение обновления Service Worker: запись и рейтинг 4,5 сохранились после обновления.
